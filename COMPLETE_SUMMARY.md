## 🚀 QUICK START (3 STEPS)

### Step 1️⃣: Build APK

**Windows:**
```bash
cd freefireclone-panel
.\build-apk-complete.bat
```

**Mac/Linux:**
```bash
cd freefireclone-panel
chmod +x build-apk-complete.sh
./build-apk-complete.sh
```

**Output:** 
```
✅ APK created at: bin/Release/net6.0-android/com.freefireclone.panel.apk
```

---

### Step 2️⃣: Install on Phone

**Method A - Direct File Transfer (Easiest):**
1. Copy APK to phone via USB
2. Open Downloads folder
3. Tap APK → Install
4. Done!

**Method B - Using ADB:**
```bash
adb install -r bin/Release/net6.0-android/com.freefireclone.panel.apk
```

---

### Step 3️⃣: Use the App

1. Tap "Free Fire Client" in app drawer
2. Click START button
3. Toggle ES/AIM/FL switches
4. Watch real-time updates
5. Click STOP to deactivate
