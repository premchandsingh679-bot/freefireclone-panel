# Release v1.0 - Free Fire Client Panel

## 🎉 Initial Release

This is the first stable release of **Free Fire Client Panel** for Android.

### 📦 Downloads

- **APK File**: `FreeFireClientPanel.apk` (Debug Build)
- **Size**: ~20 MB
- **Format**: ARM64 (64-bit)
- **Min Android**: 5.0 (API 21)

### ✨ Features Included

#### Core Features
- ✅ **Enemy Sensor (ES)** - Real-time enemy detection toggle
- ✅ **Auto Aim (AIM)** - Precision targeting system toggle
- ✅ **Flash Light (FL)** - Night vision / light enhancement toggle

#### Dashboard
- ✅ **Active Features Counter** - Shows enabled features (0-3)
- ✅ **Uptime Timer** - MM:SS format tracking
- ✅ **Client Status Monitor** - Connection state indicator
- ✅ **Timestamp Display** - Last update time

#### User Experience
- ✅ **Material Design UI** - Dark theme professional look
- ✅ **Toast Notifications** - User feedback on actions
- ✅ **Color Coding** - Green (active), Red (inactive)
- ✅ **Responsive Layout** - Scrollable interface
- ✅ **Auto-save Preferences** - Persistent storage

#### Controls
- ✅ **START Button** - Activate client & start timer
- ✅ **STOP Button** - Deactivate all features
- ✅ **Toggle Switches** - Per-feature control
- ✅ **Real-time Updates** - Instant UI feedback

### 🚀 Installation

**Easiest Method:**
1. Download `FreeFireClientPanel.apk`
2. Transfer to Android phone
3. Open file → Tap Install
4. Done!

**Alternative (ADB):**
```bash
adb install FreeFireClientPanel.apk
```

### 📱 System Requirements

- Android 5.0 or higher
- 512 MB RAM minimum
- 50 MB free storage
- ARM-based processor

### 🎮 Usage

1. **Start Client**: Tap START button
2. **Toggle Features**: Flip ES/AIM/FL switches
3. **Monitor Status**: Watch real-time updates
4. **Stop Client**: Tap STOP button
